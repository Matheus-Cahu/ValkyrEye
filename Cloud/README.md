# Cloud

Serviço futuro para receber fotos ou vídeos com metadados de alerta, armazenar
os arquivos e classificar o conteúdo como pessoa, animal, outro ou inconclusivo.

O Raspberry Pi deve manter uma cópia local até receber a confirmação do upload.
O [contrato de eventos](../docs/ARQUITETURA.md) liga a imagem ao sensor que
originou o alerta.
